# Overview
The MYDFIR Wazuh Challenge is a free 7-day guided build of a SOC lab consisting of three VMs:
- An Ubuntu server to configure and run Wazuh
- A Windows VM to install sysmon and Wazuh agent
- An Ubuntu VM to install sysmon and Wazuh agent

Learning activities include:
- Simulating hacker activity to generate telemetry and search for events on Wazuh.
- Building SOC dashboards.
- Setting up File Integrity Monitoring (FIM) and creating a custom detection rule.
- Configuring Active Response.
- Investigating alerts and creating [analyst reports](./analyst_reports.md).

You can build yours too! Here's the complete YouTube playlist for the [Wazuh SOC Analyst Challenge](https://www.youtube.com/show/VLPLR6URv8tFDJE?sbp=KgtkdUVpYlJHWU1Ib0AB)
