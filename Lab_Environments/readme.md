These purpose-built labs are ones I built outside of any learning platforms like TryHackMe, MYDFIR, LetsDefend, etc...

The inspiration may have come from watching a video or reading an article, or even asking AI one Saturday morning, "What no-cost to low-cost cybersecurity lab can I build over a weekend?".

Hopefully you can use the information here to jumpstart your own cybersecurity lab builds.

Happy building!!!


# Labs
- [Raspberry Pi Cyber Lab](./Raspberry_Pi/)

  A headless device that runs 24/7 and only accessible via ssh. Initially built to learn OWASP web application security by running a docker instance of Webgoat/Webwolf. Yes, you can totally use a VM but where's the fun in that? Plus, you have to give up some of the RAM on your host machine. I presented this lab to the Cover6 Community Meetup - First Time Speaker session on 10/28/26. Check out the [PDF file for the slide deck](./Raspberry_Pi/Raspberry_Pi_Cyber_Lab_15_Minute_Talk.pdf).
