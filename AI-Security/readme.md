# Overview

This section documents my ongoing learning and hands-on exploration of AI security, including threat modeling, prompt security, AI supply-chain attacks, data poisoning, and the security risks associated with agentic AI systems.

My learning draws from multiple sources, including structured hands-on platforms such as TryHackMe, Oracle's learning resources on Agentic AI, independent research, and practical experimentation.

I'm also developing an independent AI security lab to investigate concepts, test security controls, and explore scenarios beyond the scope of predefined course environments. The goal is to build a deeper understanding of how AI systems can be attacked, how those risks can be identified, and how they can be mitigated.

This is an evolving collection of lab notes, investigations, research, and practical exercises.
